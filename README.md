# English Learning Review Cards

This is a lightweight personal review site for English phrases, collocations, grammar patterns, and polished sentences.

## Add New Content

Phrase entries live in `entries/phrases.md`.

```md
## come to terms with
- meaning: 接受并逐渐适应困难事实
- example: Many students have to come to terms with the pressure of studying abroad.
- usage: 描述适应变化、面对压力、接受现实
- tags: writing, speaking, academic
- date: 2026-05-17
```

Sentence entries live in `entries/sentences.md`.

```md
## The value of education lies not only in acquiring knowledge, but also in learning how to think independently.
- meaning: 教育的价值不仅在于获取知识，也在于学会独立思考。
- takeaway: lies not only in..., but also in...
- usage: writing task 2; 教育、成长、社会话题
- tags: writing, academic
- date: 2026-05-17
```

Keep the field names in English: `meaning`, `example`, `usage`, `takeaway`, `tags`, and `date`.

## Review Features

- Browse phrase cards and sentence cards separately.
- Search English text, Chinese notes, usage notes, and tags.
- Filter by tags such as `writing`, `speaking`, `academic`, `finance`, or `reflection`.
- Mark cards as `已掌握` or `待复习`. This status is saved only in your current browser.

## GitHub Pages

This repository is designed to run directly on GitHub Pages. After Pages is enabled for the `main` branch root, visit:

```text
https://contralogik.github.io/Englishlearning/
```

Every time `entries/phrases.md` or `entries/sentences.md` is updated on GitHub, the review site updates with it.
